## What I'm building

**[tribute](https://github.com/ecgang/tribute)** — Per-source attribution metering for AI answers. Measures what each retrieved source actually contributed to a generated answer, with settlement records and a tamper-evident audit trail. If AI is going to eat the web, sources should be able to prove what they were worth.

**[terminalhire](https://github.com/staqsIO/terminalhire-plugin)** — Local-first job matching for developers, surfaced in the Claude Code spinner. Your code never leaves your machine; the matching runs locally.

**AgentBOX** — Edge-AI appliance. Agent pipelines on Jetson hardware, on-prem, for teams whose data legally cannot go anywhere.

Same problem three ways: **keep the data local, prove the provenance.**
